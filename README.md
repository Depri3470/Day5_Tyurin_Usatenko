# День 5. SharedPreferences

Учебная практика УП.12 «Мобильная разработка».
Выполнили: Тюрин Александр, Усатенко Даниил, группа 2-ИСП9-77.

Приложение на Kotlin (Empty Views Activity), демонстрирующее долговременное хранение данных через `SharedPreferences`.

## Задания

| № | Задание | Где реализовано |
|---|---------|-----------------|
| 1 | Сохранение, загрузка и удаление имени пользователя с валидацией ввода | `MainActivity` |
| 2 | Сохранение тёмной/светлой темы (`Boolean`) и применение её при запуске | `MainActivity` |
| 3 | Счётчик запусков (`Int`) и паттерн First Launch | `MainActivity` |
| 4 | «Меню ресторана»: избранные блюда в `Set<String>` с копированием через `HashSet` | `MainActivity` |
| 5 | Список покупок с `ListView`, удалением по клику и сохранением порядка | `ShoppingActivity` |

## Используемые ключи

- `MyPrefs`: `user_name`, `dark_mode`, `is_first_run`, `launch_count`, `favorites_set`
- `ShoppingPrefs`: `saved_items` (элементы через разделитель `;;;`)
